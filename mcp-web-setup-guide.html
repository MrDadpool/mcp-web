Setup guide

Give your LM Studio model the web

A model running on your Mac has no internet. mcp-web is a small server that hands it four abilities: search, read a page, call an API, and render a JavaScript-heavy site. Fifteen minutes, one Terminal command.

You need LM Studio 0.3.17 or newer File mcp-web-0.1.0.zip Time ~15 min

What it can do once it's running

ToolWhat the model gets
web_searchDuckDuckGo results — title, link, snippet. No API key, no account, no quota.
fetch_urlA page's actual article text, with navigation and ads stripped out.
http_requestAny HTTP call. This is the one for JSON APIs.
render_pageLoads a page in a real headless browser and runs its JavaScript. Optional — see step 5.

Setup

  1. Unzip it somewhere permanent

    Not Downloads, and not the Desktop if you tidy it. LM Studio launches the server from wherever this folder lives, so moving it later breaks the connection. ~/mcp-web is a good home.

    It's an ordinary .zip — double-click it. Nothing to install to open it.

  2. Run the installer

    Open Terminal and run these two lines. The installer builds an isolated Python environment inside the folder — it touches nothing else on your Mac.

    cd ~/mcp-web
./install.sh

    If macOS refuses with "cannot be opened because it is from an unidentified developer", strip the download flag and try again:

    xattr -d com.apple.quarantine install.sh
chmod +x install.sh
./install.sh

  3. If it asks for a newer Python

    The server needs Python 3.11 or later. If yours is older, the installer stops and says so rather than half-finishing. Install uv, which fetches its own Python:

    curl -LsSf https://astral.sh/uv/install.sh | sh

    Close Terminal, open it again, and re-run ./install.sh.

  4. Paste the config into LM Studio

    The installer finishes by printing a JSON block with your exact path already filled in. Copy that block — don't retype it, the path has to be right.

    In LM Studio: right sidebar → Program tab → Install → Edit mcp.json. Paste and save. It looks like this:

    {
  "mcpServers": {
    "mcp-web": {
      "command": "/Users/you/mcp-web/.venv/bin/mcp-web"
    }
  }
}

    Already have other servers in there? Add "mcp-web" alongside them, inside the same "mcpServers" object.

  5. Optional: the headless browser

    Skip this. Most sites work without it. Come back only if a page returns empty because it builds itself in JavaScript.

    cd ~/mcp-web
.venv/bin/python -m pip install playwright
.venv/bin/playwright install chromium

    Downloads about 400 MB. The fourth tool, render_page, shows up the next time LM Studio starts the server.

  6. Use it

    Load a model that supports tool use, switch mcp-web on for the chat, and ask it something it can't answer from memory — today's news, a library's current version. LM Studio asks you to approve each tool call, so you can watch what it's doing before you trust it.

What it will and won't reach

By default the server refuses to connect to your own machine or your home network — localhost, 192.168.x.x, 10.x.x.x, and the rest. Every request is checked, including redirects, so a site can't bounce the model somewhere private.

This is on purpose. A model can be talked into things by a web page it just read, and without that check the first thing it could be talked into is your router's admin panel.

Turning it off opens your LAN

If you genuinely want the model to reach something running on your own machine, add an env block to the LM Studio config. Know what that exposes before you do.

"mcp-web": {
  "command": "/Users/you/mcp-web/.venv/bin/mcp-web",
  "env": { "MCPWEB_ALLOW_PRIVATE": "1" }
}

Other settings — timeouts, size caps, a host allowlist — are listed in README.md inside the folder.

If something breaks

Check the server starts at all

cd ~/mcp-web
.venv/bin/python -c "import anyio; from mcp_web.server import mcp; print([t.name for t in anyio.run(mcp.list_tools)])"

Expect: ['web_search', 'fetch_url', 'http_request'] — plus render_page if you did step 5.

The model can't see the tools

Almost always the path in mcp.json, or a model that doesn't support tool use. LM Studio prints the server's errors in the Program tab — look there first. Restarting LM Studio after editing mcp.json is worth a try.
